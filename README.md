# Modern E-Commerce Website

A modern and responsive e-commerce website built using HTML, CSS, and JavaScript.

## ✨ Features
- Modern and stylish user interface
- Responsive product layout
- Product search functionality
- Add to cart feature
- Dark mode toggle
- Hover animations
- Real product images
- Interactive shopping experience

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript

## 📱 Responsive Design
The website is designed to work on both mobile and desktop devices.

## 🎯 Purpose
This project was created to improve frontend web development skills and simulate a real-world online shopping interface.
